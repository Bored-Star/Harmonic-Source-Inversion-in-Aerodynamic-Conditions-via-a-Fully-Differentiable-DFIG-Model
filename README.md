# Harmonic-Source-Inversion-in-Aerodynamic-Conditions-via-a-Fully-Differentiable-DFIG-Model
Using differentiable programming to invert harmonic sources in DFIG systems, this work finds that only hub wind speed is reliably identifiable among aerodynamic parameters due to underdetermined observations, while AD and FD perform comparably on flat loss surfaces with AD marginally slower.
